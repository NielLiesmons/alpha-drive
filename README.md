# Alpha Drive

Encrypted personal / space files on **cryptree + WebDAV** (WebDavE).

## Status

Stub. Implementation will grow from the cryptree / state work already explored in Alpha Chat.

## Goals

- Private trees with ACLs per folder/file
- Optional **public** subtrees for content meant for the web (newsletters, blog posts, media)
- Simple **HTTP API** so any site (e.g. Ferme de Bley) can list and fetch public posts
- MNS (later) points at Drive authority endpoints; **DNS + HTTPS work from day one**
